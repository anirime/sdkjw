# 전자구역카드

구역 목록/지도, 방문 기록, 구역 배정을 관리하는 PWA 앱입니다. React + Vite로 만들었고 카카오맵으로 지도를 표시합니다.

## 시작하기

```bash
npm install
cp .env.example .env   # 카카오 JavaScript 키 입력
npm run dev
```

### 카카오맵 API 키 설정

1. [카카오 개발자 콘솔](https://developers.kakao.com)에서 애플리케이션을 생성합니다.
2. "제품 설정 > 카카오맵"을 활성화합니다.
3. 앱 요약 정보에서 JavaScript 키를 복사해 `.env`의 `VITE_KAKAO_MAP_APP_KEY`에 입력합니다.
4. "플랫폼 > Web"에 실행 도메인(`http://localhost:5173` 및 배포 도메인)을 등록해야 지도가 정상 동작합니다.

키가 없으면 지도 영역에 안내 메시지가 표시되고, 나머지 기능(구역/주소/방문기록/배정)은 정상적으로 동작합니다.

## 주요 기능

- **구역 목록/지도 보기**: 구역별 주소를 지도 위 마커와 목록으로 확인, 지도를 클릭해 새 주소 추가
- **방문 기록 관리**: 주소별 방문 여부/결과(방문함, 부재중, 거절, 방문 사절, 재방문 요망)와 메모 기록
- **구역 배정/담당자 관리**: 담당자 등록, 구역 배정/반납 처리, 배정 이력 조회

## 데이터 저장

현재는 브라우저 IndexedDB에 로컬로 저장됩니다(기기 간 동기화 없음). 여러 사용자가 데이터를 공유하려면 별도 백엔드 연동이 필요하며, `src/db.ts`의 함수들을 API 호출로 교체하면 됩니다.

## PWA

`vite-plugin-pwa`로 오프라인 캐싱과 설치 가능한 앱(manifest)을 제공합니다. `npm run build && npm run preview`로 프로덕션 빌드에서 서비스워커 동작을 확인할 수 있습니다.

## 스크립트

- `npm run dev` — 개발 서버 실행
- `npm run build` — 타입 체크 후 프로덕션 빌드
- `npm run preview` — 빌드 결과 미리보기
- `npm run lint` — Oxlint 실행
